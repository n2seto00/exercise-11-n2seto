Azure-kysymykset

  1. Mitä tarkoittaa pilvipalvelu Azuren yhteydessä?

    Pilvipalvelussa laskenta, tallennus ja muut IT-resurssit tarjotaan internetin kautta.

  2. Mihin Azure Storage palvelua voidaan käyttää?

    Sitä voidaan käyttää esimerkiksi tiedostojen, objektien ja muun datan tallentamiseen pilveen.

  3. Mitä Azure Virtual Machine tekee?

    Se tarjoaa virtuaalisen tietokoneen, jossa voidaan ajaa käyttöjärjestelmää ja sovelluksia.

  4. Miksi sovelluksen resurssit voidaan sijoittaa samaan Resource Groupiin?

    Samaan sovellukseen liittyviä Azure-resursseja voidaan hallita yhdessä helpommin.

  5. Mitä hyötyä Azure Monitorista on sovelluksen ylläpidossa?

    Sen avulla voidaan seurata esimerkiksi sovelluksen toimintaa, suorituskykyä ja virheitä.
